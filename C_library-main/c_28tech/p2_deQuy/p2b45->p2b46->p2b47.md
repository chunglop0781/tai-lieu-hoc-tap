# 2. Stack frame là gì ?
## Stack frame là một kỹ thuật quản lý bộ nhớ xuất hiện trong một số ngôn ngữ lập trình, nó có nhiệm vụ tạo ra và loại bỏ các biến tạm thời.
## Có thể hiểu Stack frame là một tập hợp tất cả các thông tin liên quan đến một chương trình con (được tạo ra khi xuất hiện lời gọi hàm)
## Stack frame chỉ tồn tại trong quá trình chương trình thực thi, stack frame giúp các ngôn ngữ lập trình hỗ trợ được được chức năng đệ quy cho chương trình con.
## Những thành phần của stack frame có thể kể đến như biến cục bộ, đối số, địa chỉ trả về của một chương trình con.
## Mỗi khi một lời gọi hàm được thực hiện, stack frame chứa thông tin của hàm đó được đẩy vào bộ nhớ stack và khi hàm đó kết thúc thì stack frame này được loại bỏ khỏi bộ nhớ stack.

# 4. Chú ý khi viết hàm đệ quy:
## Đệ quy thường dựa trên công thức toán học gọi là công thức truy hồi và một bài toán con nhỏ nhất. Khi viết hàm đệ quy ta cần xác định được bài toán con nhỏ nhất để làm điểm dừng cho hàm đệ quy và công thức truy hồi để tìm ra lời giải của bài toán lớn hơn thông qua đáp án của bài toán nhỏ hơn.
## Nếu đệ quy không có điểm dừng, khi số lượng hàm đệ quy gọi đủ lớn sẽ làm bộ nhớ stack bị tràn.
```
#include <stdio.h>

//S(n) = 1 * 2 * 3 * ... * n

int F(int n){
  if(n == 0)
    return 1;
  else
    return n * F(n-1);
}

int main(){
  printf("%d", F(6));
  return 0;
}
```
# Một số ví dụ minh họa
## Tính số Fibonacci:
* Bài toán con nhỏ nhất : F(0) = 0 F(1) = 1
* Công thức truy hồi : F(n) = F(n - 1) + F(n - 2) khi n >= 2
* Code này chạy rất chậm, độ phức tạp là 0(1.618^n)

```
#include <stdio.h>
int fibo(int n){
  if (n == 0 || n == 1)
    return n;
  else
    return fibo(n - 1) + fibo(n - 2);
}
```

## Tính tổ hợp chập k của n:
* Bài toán con nhỏ nhất : C(n,k) = 1 nếu k = 0 hoặc n = k
* Công thức truy hồi (Công thức pascal): C(n, k) = C(n - 1, k - 1) + C(n - 1, k)

```
#include <stdio.h>
int nCk(int n, int k){
  if (k == 0 || n == k)
    return 1;
  else
    return nCk(n - 1, k - 1) + nCk(n - 1, k);
}
```

## Tính tổng chữ số của số nguyên dương n: SumDigit(n)
* Bài toán con nhỏ nhất : SumDigit(n) = n nếu n < 10
* Công thức truy hồi : SumDigit(n) = n % 10 + SumDigit(n / 10) nếu n >= 10

```
#include <stdio.h>
int SumDigit(int n){
    if (n < 10)
      return n;
    else
      return n % 10 + SumDigit(n / 10);
}
```

# [Đệ Quy]. Bài 7. Tính tổ hợp chập K của N
* Cho 2 số nguyên dương N và K. Hãy tỉnh tổ hợp chập K của N. Tiện thể các bạn ôn lại một vài tính chất của hợp chập K của N nhé.
* Số các tổ hợp chập k của n phần tử:
* Qui ước:
*     nC0 = 1
*     nC0 = nCn = 1
*     nCk = (n-1)C(k-1) + (n-1)Ck
*     nCk = [(n-k+1)/k] * nC(k-1)
## Input Format
* 2 số nguyên dương N và K.
## Constraints
* 0<=k<=n<=10; Chú ý các bạn phải code bằng đệ quy nhé.
## Output Format
* Kết quả của tổ hợp chập K của N.
## Sample Input 0

```
10 2
```

## Sample Output 0

```
45
```

## Submit
```
#include <stdio.h>


int tohop(int n, int k){
  if(k == 0 || n == k){
    return 1;
  }
  else{
    return tohop(n - 1, k - 1) + tohop(n - 1, k);
  }
}

int main(){
    int n, k;
    scanf("%d%d", &n, &k);
    printf("%d", tohop(n, k));
    return 0;
}
```

# [Đệ Quy]. Bài 9. Lũy thừa nhị phân.

* Cho 2 số nguyên không âm a và b. Hãy tỉnh a^b%(10^9-7), Kiến thức bạn cần sử dụng là Binayr Exponentiation.
```
Fast Modular Exponentiation

$$(a \cdot b) \pmod n = ((a \pmod n) \cdot (b \pmod n)) \pmod n$$

$$X^Y \pmod N = \begin{cases} \left(X^{\lfloor \frac{Y}{2} \rfloor} \pmod N\right)^2 \pmod N & \text{if } Y \text{ is even} \\ \left(\left(X^{\lfloor \frac{Y}{2} \rfloor} \pmod N\right)^2 \pmod N\right) \cdot X \pmod N & \text{if } Y \text{ is odd} \end{cases}$$

We can save the value of $\left(X^{\lfloor \frac{Y}{2} \rfloor} \pmod N\right)$ to not compute it twice.

$$\mathcal{O}(\log(n))$$
```

## Input Format
* 2 số nguyên dương a và b.
## Constraints
* 1<=a,b<=10^12;
## Output Format
* In ra UCLN và BCNN của 2 số. Dữ liệu đảm bảo UCLN của 2 số nằm trong khoảng số nguyên 64 bit.
## Sample Input 0

```
2 10
```

## Sample Output 0

```
1024
```

## Submit
```
#include <stdio.h>

#define ll long long

const int mod = 1000000007;

ll binpow(ll a, ll b){
    if(b == 0){
        return 1;
    }
    ll tmp = binpow(a, b / 2);
    if(b % 2 == 1){
        return ((tmp % mod) * (tmp % mod)) % mod * (a % mod) % mod;
    }
    else{
        return (tmp % mod) * (tmp % mod) % mod;
    }
}

int main(){
    ll a, b;
    scanf("%lld%lld", &a, &b);
    printf("%lld", binpow(a, b));
    return 0;
}
```
