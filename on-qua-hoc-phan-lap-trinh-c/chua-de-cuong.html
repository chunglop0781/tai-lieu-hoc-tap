Giải thích C: for, struct, fgets, strcspn, fclose

1. Cấu trúc struct

struct trong C dùng để định nghĩa một kiểu dữ liệu mới bao gồm nhiều thành phần khác nhau, ví dụ:

struct SinhVien {
    char ten[50];
    int tuoi;
    float diem;
};

Ý nghĩa:

  • char ten[50]; – lưu tên sinh viên (chuỗi ký tự).
  • int tuoi; – lưu tuổi.
  • float diem; – lưu điểm trung bình.

2. Vòng lặp for

Vòng lặp for dùng để lặp lại một khối lệnh nhiều lần:

for(int i = 0; i < 5; i++) {
    printf("%d\n", i);
}

Ý nghĩa:

  • int i = 0; – khởi tạo biến đếm.
  • i < 5; – điều kiện lặp.
  • i++ – tăng biến đếm sau mỗi lần lặp.

3. Hàm fgets

fgets đọc một dòng từ tệp hoặc bàn phím:

char buffer[100];
fgets(buffer, 100, stdin);

Ý nghĩa:

  • buffer – nơi lưu dữ liệu đọc được.
  • 100 – số ký tự tối đa đọc (bao gồm ký tự kết thúc \0).
  • stdin – nguồn dữ liệu (bàn phím).

4. Hàm strcspn

strcspn trả về số ký tự từ đầu chuỗi đến khi gặp ký tự trong tập ký tự cho trước:

buffer[strcspn(buffer, "\n")] = 0;

Ý nghĩa:

  • Xác định vị trí ký tự \n trong chuỗi buffer.
  • Gán 0 để loại bỏ ký tự xuống dòng khi đọc từ fgets.

5. Hàm fclose

fclose đóng tệp đã mở để giải phóng tài nguyên:

FILE *fp = fopen("data.txt", "r");
fclose(fp);

Ý nghĩa:

  • fopen mở tệp.
  • fclose đóng tệp khi không còn cần đọc/ghi nữa.
